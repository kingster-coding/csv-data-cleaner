# CSV Data Cleaner

A Python script that cleans messy CSV data automatically using pandas.

## What it does

- Removes duplicate rows
- Trims extra spaces from text
- Fixes name and city capitalization
- Fills missing values with "Not Provided"
- Keeps phone numbers in the correct format
- Saves the result as `cleaned.csv`

## How to use

```bash
pip install pandas
python cleaner.py
```

## Example

- Input: `sample.csv` (15 messy rows)
- Output: `cleaned.csv` (12 clean rows)
